## Стек

Next.js 16 (App Router), React 19, TypeScript, ESLint. Без внешних зависимостей и без CSS-фреймворков — только CSS-модули.

## Что показывает пример

- `/` — страница рендерится на сервере на каждый запрос: в HTML уже подставлены `requestId`, время рендера, данные запроса (`Host`, IP, `User-Agent`) и информация о процессе Node.js. Кнопка «Отрендерить заново» вызывает `router.refresh()` — сервер собирает разметку повторно, без перезагрузки страницы.
- `/posts` — SSR с запросом во внешний API: `fetch` выполняется на сервере, список обёрнут в `<Suspense>` и догружается стримингом.
- `/api/server-info` — route handler, отдаёт те же серверные данные в JSON.

Ключевые файлы: [`lib/server-info.ts`](lib/server-info.ts) — сбор данных запроса через асинхронный `headers()`, [`app/page.tsx`](app/page.tsx) — серверный компонент страницы, [`components/`](components) — клиентские компоненты (`'use client'`).

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме
npm run dev

# сборка для продакшн
npm run build

# запуск собранного приложения
npm run start
```

Приложение стартует на http://localhost:3000, порт можно изменить переменной окружения `PORT`.

## Как убедиться, что это SSR

```bash
curl -s http://localhost:3000 | grep -o 'data-request-id="[^"]*"'
```

Значение приходит уже в HTML и меняется при каждом запросе — разметку собирает сервер, а не JavaScript в браузере. Если отключить JS в браузере, страница останется читаемой: пропадёт только интерактив (кнопка и время в браузере).

## Как это работает

В App Router компоненты по умолчанию серверные. Страница рендерится на каждый запрос, если использует request-time API или некешированные данные:

- `headers()`, `cookies()`, `searchParams` — асинхронные API текущего запроса (в примере — `lib/server-info.ts`);
- `fetch()` — в Next.js 16 не кешируется по умолчанию (в примере — `app/posts/page.tsx`);
- `connection()` из `next/server` — если своих данных у страницы нет, но результат должен быть разным для каждого запроса (например, `Math.random()`).

Клиентские компоненты помечаются директивой `'use client'`: их HTML тоже приходит с сервера, а в браузере они гидратируются и получают интерактивность.
